## 5. 시나리오 — 1부: 유비전 (27스테이지 + 분기 슬롯)

주인공 시점: **유비** (영걸전 직계). 구조: **사실 모드 본선 + 가상 모드 분기** (조조전의 분기 재미 이식). v1은 사실 모드만, 가상 분기는 업데이트.

> 🎬 **캠페인 루프 (구현 2026-06-15, W1 시스템 완료)**: 고립 전투 → **stages → intro 시나리오 씬 → 상점/편성(/prep) → 전투 → outro 씬 → 다음 스테이지 intro(자동 연결)**.
> - 막간 시나리오 = 스테이지 JSON `scenario{intro,outro,outroDefeat?}`(ScenarioScene = bg + DialogueLine[]). 전용 풀스크린 `ScenePlayer`(배경+화자 초상+타자기 — **VN 버스트 방식 = 조조전 막간 정합**, 인물은 화자 초상으로 등장하고 배경은 인물 없는 빈 공간). 라우트 `/scene?stage=ID&type=intro|outro`. **빈 씬 가드** — 시나리오 없는 스테이지는 즉시 다음 단계로(점진적 콘텐츠).

> - **이미지 = 임의 placeholder + 드롭-인 업그레이드**: `AssetImage`가 경로 규약(`/assets/ui/portraits/{id}.webp`, `/assets/scenes/{bgId}.webp`)에 파일 있으면 표시, 없으면 placeholder. 필요 목록 = **에셋 매니페스트**(`pnpm --filter @tk/sim asset-manifest` → docs/reference/asset-manifest.md, 길중 생성 요청서).
