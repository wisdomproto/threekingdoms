# Creator Shell 목업 메모 (2026-09-12, 길중 제공 이미지)

> 길중이 보낸 저작도구 예시 이미지(「삼국지 시나리오 에디터 — 제5장 사수관 전투」)를 텍스트로 옮긴 기록. 원본 PNG는 `docs/design/creator-shell-mockup.png`로 저장할 것(이미지 파일은 이 커밋에 없음). design-guide §4 Desktop Layout·master-plan §14~16의 **P2 챕터 중심 Creator**의 시각 목표.

## 구조 (읽은 그대로)
- **상단 Project Bar**: 앱 로고 · 「삼국지 / 제5장 사수관 전투」 브레드크럼 · `Draft` 배지 · ↶ ↷ · "저장됨 ✓ 2024.12.10 14:28" · **▶ 이 장 테스트**(드롭다운) · ⚙
- **좌측 Chapter rail**: 프로젝트 카드(삼국지 · 총 12개 장) · 메뉴(개요 / 장(시나리오) / 등장인물 / 공통 에셋 / 설정) · **장 목록**(썸네일 + "컷신 N · 전투 N", 잠긴 장은 🔒) · 「+ 장 추가」
- **중앙 Workspace**: painted 배경 위 격자 전투 맵. 좌측 도구열(선택/펜/지우개/영역/깃발/큐브), 상단 지형 팔레트(지형: 평지 …) + 토글(그리드 표시·이동 범위·공격 범위·지형 정보), 우상단 미니맵, 우하단 지형 정보 칩(지형 효과 · 평지 · 이동 1 · 방어 ±0%). 선택 유닛은 이동 범위(파랑)·이동 경로 화살표 표시.
- **하단 탭**: 스토리 · **전투** · 이벤트 · 등장인물 · 보상 · 에셋 — 전투 탭 = 전투 개요(썸네일 + 설명 + 추천 레벨/예상 턴/맵 크기 칩) + 주요 이벤트 목록(번호 · 트리거 · 이벤트 ID).
- **우측 Inspector**(선택된 유닛): 초상 · 이름 · 진영/주요 인물 배지 · Lv 스테퍼 · 대사 인용 · 탭(기본 정보/능력치/스킬/메모) · 부대 타입 · 소속 · 배치 위치 X/Y · 방향 · **주요 장비**(청룡언월도 + 보조 장비 슬롯) · **이벤트 트리거**(등장 시 대사 EVT_005 / 지정 위치 도달 EVT_012 / + 트리거 추가) · **전투의 승패 조건(현재 장)**(승리: 적 장수(화웅) 격파 / 패배: 유비의 패주·아군 전원 격파 / + 조건 추가).

## 현행과의 대응 (P2 착수 시 출발점)
| 목업 | 현행 |
|---|---|
| Project Bar(Draft·저장됨·Undo/Redo·▶ 이 장 테스트) | `tools/stage-editor.html` 툴바 — 저장/Publish 검사/▶ 이 스테이지 테스트(2026-09-12), Undo만(Redo 없음), Draft 배지·저장 상태 표시 없음 |
| Chapter rail | `#stageSelect` 드롭다운(27스테이지) — 썸네일·컷신/전투 수 없음 |
| Workspace(격자+팔레트+미니맵+범위 토글) | 지형 칠하기·유닛 배치·검증 있음, painted 배경 미표시, 이동/공격 범위 토글 없음 |
| 하단 탭(스토리/전투/이벤트/등장인물/보상/에셋) | 스테이지 탭(메타·유닛·목표·증원/전략) — 스토리(`scenario`)·이벤트(`dialogue`)는 **편집 UI 없음**(P0로 보존만 됨) |
| Inspector(정의/인스턴스 구분, 장비, 트리거, 승패) | 유닛 카드(commanderId·classId·level·troops·items·side·x,y) — 초상·정의/인스턴스 구분·트리거 UI 없음 |

## 주의
- 목업의 "방향(아래쪽 ↓)" 필드는 현 스키마에 없음(SD facing은 screen-left 고정 + 코드 미러). 채택하려면 스키마 결정 필요.
- 목업의 이벤트 ID 표기(EVT_005)는 내부 ID 노출 — design-guide §4 "내부 ID는 Advanced에서만"과 상충. 목록에는 이름을, ID는 Advanced에.
