# 기본·고급 모드 제안 및 UI 검토

2026-09-14 사용자 제안: 쉬운 버전과 개발자 버전을 나눈다. 권장 제품명은 기본 모드 / 고급 모드다. 별도 제품이나 별도 저장 포맷이 아니라 같은 프로젝트에 대한 표시 수준으로 설계한다. 이 문서는 제안과 검토 기록이며 모드 UI 구현 완료를 뜻하지 않는다.

## 실제 화면에서 확인한 문제

- 기존 편집기 1366×900: 장 목록 220px, 지형 도구 178px, 맵 628px, 인스펙터 340px로 네 영역이 항상 나란히 표시된다. 본문·보조 문구 다수가 약 11~12px로 작다.
- 전투 전 이야기 탭을 선택해도 맵과 지형 도구가 유지된다. 이야기 작성은 오른쪽 340px 안에서 이루어져 긴 대사에 불리하다. 스토리 작업면은 대사·장면 미리보기가 중심이어야 한다.
- 탭 제목이 두 줄로 꺾이고, 기본 메타 화면에 stage id, mapId, turnLimit, levelCap 등 내부 이름이 그대로 노출된다.
- 저장, Draft, Published, Publish가 혼용된다. 실제 자동저장 상태는 표시하지만 사용자가 저장과 게임 반영의 차이를 이해하기 어렵다.
- 작업 탭은 클릭 가능한 DIV이며 role이나 키보드 포커스가 없다. 키보드만으로 탭을 전환할 수 없다.
- Studio의 좁은 화면은 한 열로 배치되지만 프로젝트 작업·저장 도구·프로젝트 설정이 편집 내용보다 먼저 큰 공간을 차지한다. 선택한 단계와 편집 내용을 먼저 볼 수 있게 상단을 줄일 필요가 있다.
- 기존 편집기는 실제 1366px와 1280px 폭에서 검사했다. 요청한 390px 크기가 해당 탭에는 적용되지 않아 모바일 동작은 검증 완료로 간주하지 않는다.

## 모드별 작업

| 영역 | 기본 모드 | 고급 모드 |
|---|---|---|
| 챕터 | 이야기·전투 카드, 순서, 승리·패배 후 연결 | 리소스 ID, 세부 분기·참조 진단 |
| 이야기 | 화자·대사·배경 선택, 장면 미리보기 | MapScene 명령, JSON, 상세 타이밍 |
| 전투 | 장수 배치, 턴 제한, 승리 조건, 보상 | 증원 조건, 전략 조건, 카메라 수치, 내부 식별자 |
| 저장 | 자동저장 상태, 테스트, 게임에 반영 | 파일 내보내기, 검증 상세, 게시 변경 내역 |

## 전환 계약

1. 모드 전환은 화면 상태만 바꾸며 프로젝트 데이터를 재직렬화하거나 초기화하지 않는다.
2. 숨긴 고급 설정은 보존하고 해당 영역에 ‘고급 설정 적용 중’을 표시한다. 눌렀을 때 그 설정을 열어야 한다.
3. 기본 모드에서도 저장 실패, 다른 탭과의 충돌, 실행을 막는 잘못된 참조는 숨기지 않는다.
4. JSON 직접 편집은 고급 모드 안의 별도 작업으로 두며 적용 전 오류 위치와 변경 대상을 보여준다.
5. 모드 선택은 사용자 환경 설정이다. 작업 중 선택한 챕터·단계와 Undo 이력도 유지한다.

## 적용 순서

먼저 공통 저장을 연결한다. 다음으로 작업 종류별 화면을 만든다(스토리는 넓은 글쓰기, 전투는 맵 중심). 그 위에 기본·고급 표시 수준을 얹는다. 모드 토글만 추가하고 기존 네 패널을 그대로 유지하는 것으로는 핵심 가독성 문제가 해결되지 않는다.

## 1차 구현

- Studio와 기존 맵·스테이지 편집기에 기본/고급 모드를 추가했다. 사용자 환경 설정으로 보관하며 프로젝트 파일은 바꾸지 않는다.
- 기본 모드에서는 내부 메타·증원/전략 탭, 초상 ID, 맵 씬 JSON을 숨긴다. 적용 중인 고급 설정은 버튼으로 알려준다. Studio의 배치 수치는 접힌 상세 영역에 둔다.
- 스토리·전투 중 대사 탭에서는 맵과 지형 도구를 접고 글쓰기 공간을 넓힌다. 폼 글씨·입력 높이를 키우고 탭에 키보드 Enter/Space 조작을 추가했다.
- 좁은 화면의 전투 편집은 지형 도구 → 스크롤 가능한 맵 → 설정창 순으로 쌓인다. 전체 모바일 터치 조작 인수검사를 완료한 것은 아니다.
- Studio의 ‘장면 상세 편집’ 또는 ‘맵·장수 배치 편집’으로 기존 도구를 연다. 같은 프로젝트에 자동저장하고 선택한 챕터·단계를 유지한 채 돌아온다. 별도 Python 서버가 필요하지 않다.
- 모드 변경은 상세 편집기를 재시작하지 않는다. 같은 편집 세션의 데이터와 Undo/Redo를 유지한다. Studio로 복귀할 때는 최신 저장본을 새 기준선으로 읽는다(두 편집기의 Undo 스택을 합치지는 않는다).
- 후속으로 캐릭터·로스터와 아이템 편집기에 프로젝트 저장 및 기본/고급 모드를 연결했다. 병종·리그 편집기는 아직 이 연결 대상에 포함하지 않았다.
