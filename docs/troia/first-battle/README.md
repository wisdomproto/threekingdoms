# TROIA — 제1전투 「낯선 해안」

기획·아트 패키지 v0.2 · 2026-09-15 · 귀요미 캐릭터 방향 반영

**실행판 추가:** [첫 전투 플레이](http://localhost:3000/troia) · [기존 엔진 연결 및 확정 규칙](playable.md). 아래는 초기 기획이며, 실행판은 봉화대 도착 즉시 승리·장착형 30% 방어 가호·공유 붕대 규칙을 사용한다.

**2026-09-16 확장판:** 40×24칸 · 카메라 1.6배 · 20턴 · 봉화대 (34,8). 아래 원래 18×12 기획은 초기 기록이며, 현재 배치와 규칙은 [실행판 문서](playable.md)를 따른다.

## 확정한 방향

- 인간의 선택과 관계를 중심으로 하는 트로이 전쟁 SRPG.
- 캐릭터는 2.5~3등신 귀요미 스타일. 큰 머리·짧은 팔다리·명확한 표정으로 성인 인물을 데포르메한다. 이야기의 진지함은 유지한다.
- 신은 가호, 유물, 환경의 징후로 간접 개입한다. 전장에 직접 등장해 문제를 해결하지 않는다.
- 초기 기획·아트 자료와 실행 가능한 첫 전투를 포함한다. 구현 상태와 검증은 playable.md를 따른다.
- 트로이 전쟁 전승에서 출발한 창작 각색이다. 상륙 순서, 이 전투의 사건과 대사, 수비대장 디오레스는 본 작품용 창작 설정이다. 전승의 실제 순서나 인물에 대한 고증 자료로 사용하지 않는다.

## 한 장의 경험

**처음에는 아킬레우스의 강함에 끌리고, 끝에서는 적도 집으로 돌아가려는 사람임을 알게 한다.**

오프닝 2~3분 → 출진 안내 30초 → 전투 8~12분 → 후일담 1~2분. 총 12~18분을 목표로 하되 실제 플레이 검증 전 추정이다.

전투를 시작할 때 세 가지를 알면 충분하다.

1. 우리는 바다를 건너와 상륙로를 확보해야 한다.
2. 아킬레우스는 강하지만 파트로클로스와 병사들을 지켜야 한다.
3. 수비대장은 시간을 끌고 있다. 왜 그러는지는 진행 중 드러난다.

## 전투 구상

- 제목: 낯선 해안
- 플레이 진영: 그리스 상륙대
- 아군: 아킬레우스, 파트로클로스, 창병 1, 궁병 1
- 적군: 디오레스, 창병 3, 궁병 2
- 이동판: 18 × 12 정방형 칸. 가로로 긴 해안에서 서쪽 → 동쪽으로 진행.
- 기본 목표: 봉화대 목표 칸을 적 없이 아군이 점유한 상태로 아군 턴을 종료한다.
- 패배: 아킬레우스 또는 파트로클로스 전투불능, 또는 10턴 종료까지 목표 미달성.
- 선택 도전: 아군 전원 생존 / 7턴 이내 목표 확보. 디오레스 격파나 주민 추격은 보상 조건이 아니다.
- 봉화는 신호를 보내기 위한 시설이다. 이번 전투에는 화재 확산을 넣지 않는다.

### 진행 이벤트

| 시점 | 사건 | 의도 |
|---|---|---|
| 시작 | 아킬레우스 이동·공격 안내 | 두 개의 기본 조작만 학습 |
| 첫 아군 피해 이후, 다음 아군 행동 전 | 파트로클로스가 붕대 사용을 안내 | 회복 도구 학습. HP가 줄지 않았다면 안내 생략 |
| 2턴 시작 | 해안 주민이 동쪽 길로 빠지는 짧은 이야기 컷 | 적이 시간을 버는 이유 공개. 주민은 표적이나 전투 유닛으로 생성하지 않음 |
| 3턴 시작 | 디오레스가 봉화대 방어선으로 이동하려 함 | 인간적인 적의 목적을 행동으로 표현. 이동은 정상 이동 규칙과 경로를 따름 |
| 디오레스 HP 30% 이하 | 단 한 번 철수 대사, 이후 동쪽 출구를 향해 이동 | 순간이동이나 강제 무적 없이 철수 의도를 표현 |
| 목표 확보 | 전투 즉시 종료 → 승리 후일담 | 남은 적 처치를 강요하지 않음 |

이벤트의 턴, 수치, AI 의도는 신규 기획값이며 현재 엔진 지원 여부와 밸런스 검증을 거치지 않았다. 승리 판정은 아군 턴 종료에서 먼저 하고, 10턴의 최종 패배 판정은 그 뒤에 한다. 동일 틱의 승리와 패배 이중 처리를 금지한다.

### 테티스의 조개 부적 — 제안 규칙

아킬레우스가 출진 때부터 소지한 1회 사용 가호. 아군 행동 전에 직접 사용한다. **다음에 받는 직접 공격 피해를 30% 감소**시키고 소모된다. 전투 종료까지 공격을 받지 않으면 이 전투의 보호 상태만 종료한다. 첫 장에서는 전투당 1회, 중첩·회복·부활·확률 발동은 없다.

수치 표시: 「다음 피격 피해 −30% · 1회」. 계산 제안은 최종 직접 피해에 0.7을 곱해 내림하되, 원래 양수 피해는 최소 1. 지속 피해·환경 피해는 적용 대상이 아니며 보호를 소비하지 않는다. 미리보기와 실제 계산이 일치해야 한다. 이것은 후속 구현용 정의이며 현재 게임의 보물 계약과 동일하지 않다.

연출: 손목의 조개가 짧게 진주빛을 반사하고 파도 소리가 가까워진다. 거대한 신의 실루엣이나 광선은 없다. 인물들은 그것을 어머니의 기도라고 생각할 수 있다. 시스템 효과는 플레이어에게 명시한다.

## 지형·배치

좌표는 `(x,y)`, 왼쪽 위 `(0,0)`, x는 동쪽, y는 남쪽으로 증가한다. 아래 배치는 이미지 위에 얹을 설계 기준이다. 생성 배경의 장식과 셀 경계가 완벽히 일치한다고 가정하지 않는다.

| 영역/지점 | 위치 | 역할 |
|---|---|---|
| 바다 | x=0~2 | 통행 불가 |
| 젖은 모래 | x=3~4 | 첫 버전은 일반 이동 비용, 속도 페널티 없음 |
| 마른 해변 | x=5~17 중심 | 주 이동 공간 |
| 바위 | (8,1), (9,1), (8,10), (9,10) | 통행 불가, 중앙과 남쪽 우회로는 연결 유지 |
| 낮은 돌담 | (13,1), (14,1), (15,1) | 통행 불가 |
| 봉화대 목표 | (14,3) | 점유 가능한 목표 칸, 배경의 높은 구조물로 가리지 않음 |
| 동쪽 철수로 | (17,5) | 적 철수 출구 |
| 작은 해안 제단 | (8,8) | 이야기용 장식, 소모품 파밍 지점 아님 |
| 아군 | 아킬레우스(6,5), 파트로클로스(5,6), 창병(5,4), 궁병(5,7) | 생성 맵의 해안선을 확인해 전원 마른 모래 쪽에 배치 |
| 적군 | 디오레스(12,5), 창병(10,4)(10,6)(13,3), 궁병(14,5)(13,7) | 초기에는 상륙 지점까지 즉시 전원 돌격하지 않음 |

## 미술 규격

- 색: 바다 청록 #204E59 / 모래 #D8C59F / 청동 #A77A43 / 트로이 적갈색 #954C3D / 그리스 남색 #263B51.
- 시대감: 청동기에서 영감받은 창작 신화 세계. 현대 영화의 배우 외모나 특정 의상 디자인을 참조하지 않는다.
- 인물은 2.5~3등신의 귀여운 SD 전신 원화. 둥근 실루엣, 선명한 외곽선, 부드러운 셀 채색에 약한 붓 질감을 사용한다. 배경은 같은 팔레트의 회화로 공간감을 유지한다.
- 맵은 정투영 톱다운. 원근 지평선, 유닛, 글자, UI, 굽힌 격자는 넣지 않는다.
- 오프닝은 선상에서 해안을 바라보는 와이드 배경. 대사와 인물은 별도 레이어로 올린다.
- 생성 원본은 `assets/`에 로컬 보존하며 커밋 대상에서 제외한다. 외부 업로드하지 않는다.
