# 전투 UX P1 — Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 스펙 `docs/superpowers/specs/2026-09-12-battle-ux-p1-design.md`의 4항목 — HUD 두 컬럼 중재, 입문 공격 확인(`confirmAttack`), 패배조건 표시, 저장하고 나가기/이어하기 — 를 `apps/web`에 구현하고 실제 Chrome(CDP)로 검증한다.

**Architecture:** 순수 로직(상태기계·suspend 판정·컬럼 측 결정·조작 설정)은 node 테스트로 고정하고, HUD는 `BattleScreen`이 좌/우 flex 컬럼에 패널을 흐름 자식으로 꽂는다. 복원은 `BattleStore`에 `replayLog`를 접어 넣는 생성자 옵션 한 개. 설정은 `localStorage tk.controls.v1`, 중단 저장은 `localStorage tk.battle.suspend.v1`.

**Tech Stack:** Next 15 app router, React 19 inline-style HUD(기존 관례), `@tk/engine` `applyAction/createBattle`, vitest(node 환경, jsdom 없음 — UI 컴포넌트 단위테스트 없음), CDP E2E(`tools/editor/e2e/cdp.mjs` 재사용, Node 22 내장 WebSocket).

**Conventions:** 코드·커밋 영어, 주석은 기존 파일 관례(한국어 OK). 커밋 트레일러 `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. 브랜치 `feat/battle-ux-p1`. 작업 디렉터리 `C:\projects\threekingdoms`(pnpm 워크스페이스, `pnpm --filter web test` / `pnpm --filter web typecheck`; 패키지 이름은 `apps/web/package.json`의 `name` 확인).
