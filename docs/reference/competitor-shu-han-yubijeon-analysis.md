# 경쟁작 분석 — 「삼국지 촉한 유비전」 (蜀汉刘备传)

> **목적**: v1과 가장 가까운 현역 경쟁작의 "게임감"을 우리 용어(연출 문법·에셋·UI)로 분해해, 우리 품질 갭을 실제 작업 항목으로 환원한다.
> **작성**: 2026-07-05 (스토어 스크린샷 5장 직접 판독 + 한국 리뷰어 프레이밍). 메모리=[[competitor-shu-han-yubijeon]].
> **한계**: 정지 스크린샷 기반. 순수 타이밍(히트스톱)·오디오 레이어링·모션 리듬은 영상이 필요 — 하단 §6 캡처 체크리스트로 이연.
> **레퍼런스 이미지**: `downloads/competitor_shz/` (gitignore, 재다운로드 가능). 원본 = Google Play `com.xin.shz` 스토어 스샷.

## 0. 한 줄 요지
저쪽은 **도트인데도** 게임감이 좋다 = 그래픽 세대가 아니라 **연출 밀도·에셋 충전율·연출 문법**이 승부처다. 그리고 그 셋은 대부분 우리가 이미 백로그에 가진 항목([[game-polish-backlog]])이라, **방향이 아니라 실행의 문제**다.

## 1. 정체 / 규모
- 유비 주인공, **정사 + 가상 분기**(실시간 선택), 도트 클래식 전기(영걸전/조조전) 룩. 우리 §5와 컨셉 판박이.
- super star games studio(Android)/苏朱(iOS), 모바일 1만+ DL·평점 4.7·**2026-06-27 업뎃**(활발). "PC판"=Google Play Games on PC 에뮬(네이티브 아님).
- 한국 리뷰어 프레이밍: *"무과금 OK 누워서 즐기는 영걸전"*, *"영걸전보다 어렵다"*, *"영걸전의 재미를 뛰어넘을까"* — **영걸전 정신적 후속으로 소비됨** + F2P 친화 강조. 이게 정확히 우리가 노리는 인식 포지션인데 이미 선점 중.

## 2. 프레임 판독 — 5장

### 02_combat_fire-aoe (전투 — 화계 잭팟 순간)
- 톱다운 직교, painted 잔디 지형. 상단: 턴 `6/25턴`, 지형 `평지 (19,13)`.
- 적장 인스펙트 팝업(상단 중앙): **사마의 Lv.48 · HP 112/375 · MP 55/198 · 능동 공격 · 평지 100% · 책략 아이콘 2종(화·선회)**. = 우리 InspectPopup과 동일 정보 위계.
- **화계 AoE가 4유닛 동시 타격**: `-73 / -56 / -100 / -113` 빨강 이탤릭 대형 숫자가 각 타일 불꽃 VFX 위에 팝. 여러 숫자 동시 팝 = "대박" 밀도.
- 유닛 다양성: 보병·전차(백마)·**맹호대(호랑이 유닛)**·기병(청=적)·주술사. 병종 실루엣이 한눈에 구분됨.
- 우측 커맨드 아이콘: 저장·불러오기·정보 + 북(鼓) `턴 종료`. **아이콘이 작은 일러스트**(우리 유니코드 글리프 HUD와 대비 — [[battle-hud-fidelity]]).

**게임감 소스**: ① 다중 피해 숫자 동시 팝의 밀도 ② 숫자가 크고 빨강 이탤릭이라 "때린 느낌" 강함 ③ 불꽃 VFX가 타일마다 확실히 얹힘 ④ 병종 실루엣 가독성(호랑이·전차 등 개성 강한 병종).

### 01_scene_peach-garden (막간 — 도원결의) ★ 최대 차이점
- **막간이 별도 VN 화면이 아니라 painted 맵 위에서 진행**. 벚꽃(복숭아) 정원 painted 배경에 삼형제 SD 스프라이트가 **실제로 서 있고**(유비 홍포·관우 녹포·장비), 말풍선 `...`.
- 하단 대사창: 청동/금 장식 프레임 + 반투명 흑, **유비 실사풍 초상 흉상** + 도원결의 대사.
- ⚠ **우리 §5 결정과 정면 대비**: 우리 ScenePlayer는 "배경=인물 없는 빈 공간, 인물은 초상으로만"(VN 버스트). 저쪽은 **인물 스프라이트를 씬에 배치**해 디에게틱하게 연출 → 훨씬 "장면"처럼 보임. (우리 문법 채택 사유=54배경 재사용·베이킹 금지는 유효하나, 저쪽은 배경이 재사용 가능한 채로도 스프라이트만 얹어 리치함을 얻음.)

### 03_event_scroll-choice (이벤트 선택)
- **두루마리(족자) UI**: 양피지 스크롤 그래픽 + `선택해 주세요` 헤더(먹빛 육각 배지) + 선택지 2개에 **먹 붓터치 하이라이트**. 배경=탁현 거리(painted).
- 우리 가상 분기(§5)·보물 이벤트 선택(§10)의 폴리시 레퍼런스. 전용 이벤트 셸이 "고퀄 시나리오" 인상의 큰 축.

### 04_battle_dialogue (전투 중 대사)
- 병영(막사·울타리·천막) painted 맵. 선택 유닛에 흰 코너 브래킷 + 이동 화살표.
- 하단 유비 초상+대사 *"둘째, 셋째. 이건 우리의 첫 전투다…"* = **라이브 전투 맵 위에 오버레이**. ✔ 우리도 이미 하는 방식(전투 중 dialogue) — 여기선 갭 작음.

### 05_unit_info-radar (유닛 정보)
- 좌탭 아군/적군/지도/승패조건/신비상점/보물도감/설정. 상단 초상 로우(유비·관우·장비 실사 흉상).
- 스탯: 공격72·방어67·정신40·폭발39·사기47·이동6 + **오각형 레이더(무력80·지력80·민첩78·통솔80·운94)**.
- ✔ 검증: **운(luck) 스탯 존재** — 우리가 2026-07-03 신설한 것과 정합(§7 회심). 병종·장비·전략 탭 구조도 우리와 유사.

## 2-B. 전투 손맛 디테일 (길중 직접 플레이 관찰, 2026-07-05)
정지 스샷 못 잡는 것 중 길중이 플레이로 확인한 3가지:
1. **치명타 시 유닛 색 변화** — 저쪽은 crit에 피격 유닛이 색이 바뀜. **우리**: `playHit`이 피격 시 *항상* 빨강 틴트(`0xff8080`), 회심(crit)엔 금빛 「회심!」 팝업+임팩트만 — 유닛 자체 crit 틴트 없음. → **갭(저비용)**: 회심 시스템은 이미 있으니 회심 전용 틴트(금/백 플래시)만 얹으면 됨. `UnitView.playHit`에 crit 플래그 전달.
2. **저체력 "헉헉대는" 이미지** — 병력 일정 이하로 떨어지면 지친 스프라이트로 전환. **우리**: 병력 바 색만 주황, 스프라이트 상태 불변(idle 호흡만). → **갭**: 저체력 포즈/이펙트 미구현(포즈 추가 or 헐떡임 오버레이).
3. **공격 액션 멀티프레임** — 저쪽 공격이 1프레임 이상(플립북). **우리**: attack *포즈 1장* + 절차적 주스(앤티시페이션→오버슈트 돌진→스쿼시). → **의도적 v1 트레이드오프**(§4 "베이크 포즈+주스로 프레임 애니 대체"). 멀티프레임화는 attack 프레임 다장 생성 = 에셋 비용 큼. 주스로 충분한지는 손맛 판정 대상.

## 4. 실행 항목 (갭 → 백로그 매핑)
1. **오디오 실트랙 채우기** — BGM 5트랙 실제 작곡물 드롭인(파이프라인 완비, 실행만). 리뷰가 지목한 "게임감"의 최대 지분. → [[audio-system]]
2. **맵/씬 배경 커버리지 완성** — painted 맵 10~27, 씬 배경 03~10. 이미 🚢 출시 게이트. 저쪽 "고퀄 시나리오" 인상의 상당 부분이 **배경이 실제로 채워져 있어서**임이 확증됨. → [[game-polish-backlog]]
3. **막간 연출 문법 재검토(설계 결정 필요)** — 우리 VN-분리 vs 저쪽 디에게틱(맵 스프라이트 배치). *부분 이식 후보*: intro 일부를 전투 맵 위 스테이징으로(04처럼) — 우리는 이미 in-battle dialogue 있음. §5 재검토 안건.
4. **타격 숫자/동시팝 폴리시** — 빨강 이탤릭·대형·다중 동시 팝 밀도 벤치. FX 리듬(히트스톱 ms)은 영상 캡처 후.
5. **이벤트 선택 전용 셸** — 두루마리+먹 붓터치. 가상 분기(v1 제외지만) + 보물 이벤트 선택 대비 폴리시 레퍼런스.

- [ ] **BGM**: 전투/막간/보스 트랙 수·전환 방식·루프 길이
- [ ] **카메라**: 책략/일기토 시 줌/흔들림 유무
- [ ] **막간 연출**: 씬 전환(페이드/슬라이드)·타자기 속도·스프라이트 등퇴장 연출
