# 조조전 모드 커뮤니티 조사 — 수요·인기 모드·라이벌·제작자 관점

**조사일**: 2026-09-19 · **대상**: 네이버 카페 「조조전 클럽(조클)」 · **관련**: master-plan §1·§9·§16·§19·§20, [2026-09-17 시뮬레이션 저작도구 전략](../superpowers/specs/2026-09-17-simulation-authoring-strategy.md), [경쟁작 촉한 유비전](competitor-shu-han-yubijeon-analysis.md)

---

## 0. 결론

1. **수요는 증명됐다.** 20년 넘게 살아 있는 커뮤니티, 게시판 약 200개, 1위 모드를 100회차 이상 도는 유저, 폰에서 하려고 에뮬레이터 가이드를 1만 9천 명이 본다.
2. **1위 모드 「영걸전 RED」가 우리 공식 그대로다** — 영걸전 스토리 + 조조전 시스템(game-design §2-9). 인기의 핵심은 스토리가 아니라 **2회차 자유선택 모드·회차 특전·숨은 장수**였다.
3. **사람들은 조조전을 "유일하게 쓸 수 있는 SRPG 제작기"로 쓴다.** 아이돌·한국사·세계사·파이어엠블렘까지. SRPG 플랫폼 수요가 삼국지 카페 안에서 이미 확인된다.
4. **제작자는 20년간 돈을 한 푼도 벌 수 없었다.** 코에이 기반이라 상업 활동이 원천 불가. 1위 제작자는 본업 때문에 11개월째 멈춰 있다. 합법적 수익 분배는 우리만 줄 수 있다.
5. **진짜 라이벌은 복각유광판 — 정확히는 "AI로 개조하는 제작자 커뮤니티"다.** 한글판 등장 4주 만에 개조판 6갈래. 이들은 AI로 번역·버그 수정·측정 기반 밸런싱까지 한다. 그리고 이들이 바로 우리가 데려올 제작자다.

## 1. 조사 방법과 한계

- 방법: 로그인한 크롬에 puppeteer-core로 연결, 카페 웹이 쓰는 API로 목록·본문·댓글 첫 페이지 수집. 요청 간 수 초 간격, 총 100회 안팎.
- 범위: 게시판 목록 30여 개, 본문 약 60개. 후기 게시판은 최근 3개월(2026-06-12~09-19) 300개 제목 전수.
- 한계: 댓글은 글당 첫 페이지만. 정회원 전용 게시판 일부는 권한 부족(403). 이미지 속 정보는 못 봤다. 원문은 저장하지 않고 요약만 남긴다.

## 2. 판의 구조

- **엔진**: 거의 전부 윈도우판 조조전(1998) 실행 파일을 중국 팬들이 개조한 「신조조전」 계열(5.x → 6.0 → 6.1 → **7.0 Pro**) 위에서 돈다. 데이터는 `.e5` 파일(우리가 추출한 그 포맷), 편집기는 CczEditor·JoJoDataEditor(2010~2015년작이 여전히 최다 조회, 7.8만).
- **예외**: 복각유광판(Lua 새 엔진, §5), 「조조 더 레전드」(3D 신작, §6).
- **모드 주제**(게시판 이름 기준): 삼국지 인물전 수십 개 / 초한지 / 한국사 10 / 세계사·기타 6(징기스칸·악비·수호지·파이어엠블렘·SF) / 아이돌 9.
- **엔진 한계가 제작을 막는다** — 제작자 글에서 나온 것만: 보물 아이콘 수 부족, 병종 설명 100바이트, 예비 병종 칸 3개, 장수 번호 240 이상은 잡졸 판정, 며칠 씨름해도 못 고친 버그.

## 3. 인기 순위

**배포글 역대 조회**: 신조조전 통합(기본판, 57만) → **초한지 패왕전: 천명**(17.2만, 좋아요 1,962) → 공명전 리파인(16.9만) → 여포전 리파인(15.4만) → 영걸전 리파인(15.0만) → **영걸전 RED**(14.7만, **좋아요 2,656 — 배포 게시판 역대 최다**) … TWICE전(7.9만, 좋아요 1,548)

**최근 2년 배포 조회**: 초한지 유방전 한글판(3.1만) → 사마중달전 7.0(2.8만) → 파이어엠블렘 히어로즈 사가(1.5만) → 진격의 남만전(1.4만). 지금 뜨는 중: 성삼국촉한전, 복각유광판.

**최근 3개월 후기 수(300개 중)**: 영걸전 RED **90** / 신조조전 22 / 공명전 리파인 17 / 패왕전 16 / TWICE전 11 / 여포전 9.

→ 현재 1위는 압도적으로 RED. 초한지 패왕전의 역대 좋아요 2위는 **초한 2탄 검토의 근거**(수요 확인). 단 패왕전 스토리가 이미 "부활한 항우가 유방을 꺾는" what-if라, 우리 초한은 *어떻게* 이기느냐로 차별해야 한다.

## 4. 1위 「영걸전 RED」 해부

제작자 라미, 2023-04 완성, 1.1~1.6 패치(2025-10까지). 6.0 엔진 기반. 이전작 TWICE전·패왕전 계보를 계승.

**왜 134회차까지 하나**
1. **1회차는 이야기, 2회차부터 본게임.** 2회차부터 **자유선택 모드** — 시작할 때 "초기 아군"을 고른다. 늦게 합류하던 마초·황충을 1화부터 편성할 수 있다. 맵·시나리오는 그대로, 합류 순서 제약만 푼 것(스토리 합류 이벤트와 겹치는 중복 가입은 막아야 함 — RED도 버그로 겪음). 제작자 표현으로 회차 플레이의 핵심.
2. **아군 10명 제한** — 누구를 데려갈지가 매 회차 다른 판을 만든다.
3. **로스터 맞춤 랜덤 보물** — 영입한 장수에 맞는 보물을 준다. 일반/고유 2등급, 고유는 금테 + 도감 등록.
4. **회차 특전 선택** — 화·수·목·금·토 5종 중 선택, "선택"과 "누적" 두 갈래.
5. **숨은 장수 해금** — 제작자 퀴즈·도전 조건(예: 유비의 검술을 증명 → 손상향). 해금 기록은 다음 회차로 유지.
6. **영웅쟁패** — 장수별 도전 모드(10개 계획).
7. **난이도 사다리** — 일반 → 명예1~3 → 악몽1~3(16회차 필요) → 지옥1~3.
8. **장수별 고유 자원** — 의지·분노·격노·집중 등 스킬 비용 체계 자체가 캐릭터 개성. 주창 「칠전팔기」(쓰러질 때마다 전회복 + 강화).
9. **단계형 성장** — 동→은→금→옥→강옥, 단계마다 특성·기술 해금.
10. **보스 기믹** — 최종전 조조 체력 1,000 단위 페이즈, 최고 난이도 최종 패턴 "아군 전체 혼란"; 업 전투의 턴 경과 방어력 감소·고정 강우 턴·특정 적 처치 시 증원 차단.
11. **과감한 생략** — 적벽·이릉 이후 전투 대폭 생략. 유저도 "짧아서 회차를 많이 돌았다"고 평가.

**운영 방식** — 로드맵 공개 → 테스트 패치 → 공개 패치, 설문으로 밸런스 의견 수렴, 커뮤니티 목표(배포글 좋아요 1만 / 방송인 10명 엔딩)를 신규 장수 공개 조건으로 걸기. 회차 기록 파일을 제작자가 직접 배포(세이브가 잘 날아가서).

**멈춘 이유(2026-09-14 제작자 근황)** — 본업 부서 이동 후 과로, 상위 난이도 작업 중 못 고친 엔진 버그, 데이터 기록 파일 유실. 재개 약속 없음. 그래도 유저는 계속 회차를 올린다.

## 5. 라이벌 — 영걸전 복각유광판

- **원판**: 중국 팬 제작 「삼국지 영걸전 복각 유광판」 v12846 중문판, **Lua 기반 새 엔진**(배포 파일 `JY_LLK`). 한국엔 유튜버 소개로 먼저 알려져 번역기로 플레이되던 상태.
- **한국판 시작 2026-08-23**: 한 유저가 **Claude로 만든 한글화 패치**를 올림(조회 5.3천, 댓글 128). 번역뿐 아니라 버그 수정·성능 개선도 AI로. 스크린샷을 주면 AI가 고친다는 방식.
- **4주 만에 6갈래**: 한글판 1.0 → 1.1(모바일·개선) → 2.0(종횡 모드 확장) → V1/V2(각성·특기 50종·전투 화면) → 돗으모드 → 오리진(순정). APK는 다른 유저가 빌드.
- **규모·기능**: 전투 67개, 영입 장수 167명(술집 98·합류 61·무작위 8). 클래식/종횡 모드, 레벨 방식 선택(개별/평균), 도전 난이도 1~5(세이브·로드 불가), 역천개명(특기 1~7성), 병종 변환, 장비 특성 부여, 미니게임.
- 1.1의 **공격 전 예상 피해·책략 성공률 표시**에 유저가 "유레카"라고 반응 — 옛 게임의 불친절함이 큰 불만이었다.
- **2.0은 측정 기반으로 설계됐다**:
  - 「적장 출진」(숨은 증원·복병 처음부터 공개): 배치 1,435곳 중 숨은 적 226곳 전수 분석, 엔진에서 실제로 돌려 "서주II는 적 턴 한 번에 아군 절반 전멸"을 확인 → "아군 출진 3칸 이내 복병은 유지" 규칙 추가 → 1턴 손실 12~13%로 측정.
  - 「코스트」(장수 1~10 비용, 전투별 총량): 능력치 50% + 특기 38% + 병종 12%, 능력치는 실제 피해 공식 곡선. 단계별 세기를 "최강 조합 대비 전력 유지율, 전투 64개 평균: 96/90/81%"로 검증.
  - 숨은 장수 해금 조건에 "회차 시작부터의 **최저 난이도** 기준" — 막판에만 난이도를 올려 보상 챙기는 꼼수 차단.
- **한계**: 초상·전투 그래픽이 코에이 에셋(2.0 공지에 명시, 한글판 제작자는 영걸전 그래픽 추출도 계획) → 공개 상업화 불가. 안드로이드 APK만, 아이폰 불가. 갈래 간 세이브 비호환. 배포는 구글 드라이브.
- **편집 도구가 3주 만에 7~8개**(9/4~9/9): 통합 에디터(전투 그래픽·초상화 자동 컷/배치, 적 배치 드래그, 병종 상성·책략, 아이템, 일기토), Codex로 만든 아이템·돈 에디터, 세이브 에디터, 초상화·전투 그래픽 에디터, 한글화 에디터, 중국어 원판 동봉 에디터. 단 **전부 개인 제작·버전별 분리**("1.1 전용"), **시나리오·대사 에디터는 없음**(예정), 결과 검증·배포·권리 없음 → "이 게임을 고치는 도구"이지 "새 게임을 만드는 도구"가 아니다. 속도는 위협적 — 우리 창이 영원히 열려 있지 않다.
- 「촉한 유비전」과 같은 계열인지는 **미확인**.

## 6. 기타 주목할 프로젝트

- **조조 더 레전드**(신작, 3D): PC·스마트폰 동시, 전황 판단형 전투 AI(스킬·회복·집중 공격). 커뮤니티에 일기토를 자동 판정으로 할지 직접 조작으로 할지 묻는 중 — 우리와 같은 고민.
- **난세별곡**: 인물별 무기·갑옷·탈것 적성 → 적성에 맞는 병종일수록 더 높은 단계로 전직하는 육성 트리. RED에 자극받아 다회차·엑스트라 모드 추가.
- **초한지 패왕전**: 10회차에 숨은 캐릭터(항우 계열 3명), 30회차 달성 시 후속작 특전.

## 7. 유저 — 재미 요인과 이탈 요인

**붙잡는 것**: 아이템 조합, 좋아하는 장수를 키우는 것, 매번 다른 보물, 숨은 장수 해금, 자유모드. "1회차는 쉬운 난이도로, 2회차부터 신세계"가 커뮤니티 공통 조언. 이야기 몰입(대사 한 줄 한 줄이 좋다는 반응)도 높게 평가.

**이탈시키는 것**
- **초반 난이도 절벽** — RED 1회차 소패 전투(조조 상대 10턴 버티기)에서 포기. "어려운 스테이지가 초반에 몰려 있다."
- **중후반 대처 불가 구간** — 관우전 43화에서 이틀 시도 후 포기.
- **숨은 조건 실패** — 대화 이벤트가 안 떠서 보물을 못 얻는데 이유를 모름.
- **아군 AI** — 수송대가 보급 대신 돌격.
- **정보 부족** — 피해량·명중률을 알 수 없는 불친절함.

→ 전부 시뮬레이터(난이도 절벽), 에디터 검증(조건 누락), 결정론 예측 표시로 겨냥할 수 있는 문제.

**모바일** — 「ExaGear로 조조전 모드 하기」 가이드 조회 19,019·좋아요 107. PC 대비 70% 성능, 불안정, **아이폰 불가**라고 명시돼 있는데도 한다. 설치 없는 모바일 웹이 가장 확실한 우위.

## 8. 제작자 — 현실과 문화

**현실**
- **수익 불가**: RED 배포글이 상업 활동 일체 금지를 명시. 코에이 기반이라 구조적으로 불가.
- **번아웃**: 1위 제작자가 본업 과로로 정지. 2년 걸려 만들고 6번 패치하고도 보상은 후기·댓글·좋아요뿐.
- **배포**: 구글 드라이브 zip + 비밀번호 + 백신 오진 예외 설정 안내.
- **도구**: 10년 넘은 편집기, 시스템 이해에만 수천 조회짜리 해설글이 필요(열매·공훈 정리글 6.4천).
- **AI 사용 확산**: Codex로 편집기 제작, Claude로 번역·버그 수정, Lua 수정으로 신규 특기. 비용(토큰 사용량) 부담을 여러 명이 언급.

**문화**
- **남의 개조판을 기반으로 배포하려면 원작자 허락** — 허락 없으면 개인 플레이용.
- **에셋 권리 갈등**: 전투 스프라이트 제작자가 모바일 이식판의 무단 사용에 공개 항의(좋아요 46). 요지는 "카페 회원 제작엔 자유, 외부 이식판엔 불허". 통제가 안 되니 **작업물을 올리지 않게 된다**고.
- **모바일 이식판에 대한 반감** — 이 카페에서 "이식판"은 나쁜 이미지.
- **BGM은 애니 OST 등을 가져다 쓰는 게 관행** — UGC를 열면 그대로 들어온다.

## 10. 전략 함의

### 10-1. 경쟁 단위는 게임이 아니라 "제작자가 어디서 만드는가"

유저 관점의 "공짜 대안"은 경쟁 요인이 아니다 — 우리도 무료다. 제작자 관점에서 비교한다.

| 지금(조조전 엔진·복각판) | 우리 |
|---|---|
| 상업 활동 원천 불가 | **광고·스킨 수익 분배**(master-plan §19) — 합법적 수익의 유일한 경로 |
| 번아웃으로 정지 | 수익이 본업 시간과 경쟁할 수 있다 |
| zip + 비밀번호 + 백신 예외 | 링크 하나 |
| APK 별도 빌드, 아이폰 불가 | 웹, 아이폰 포함 |
| 엔진 빈칸 한계, 못 고치는 버그 | 데이터 제한 없음, 엔진은 플랫폼이 관리 |
| 갈래별 세이브 비호환 | 한 플랫폼, 버전 관리 |
| 에셋 무단 사용을 막을 수단 없음 | 에셋별 사용 범위 + 출처 추적 |
| 몇 명이 했는지 모름 | 플레이 수·클리어율·막히는 구간 데이터 |
| 밸런스는 손으로 또는 매번 즉석 측정 | 모든 변경에 자동 회귀 게이트 |

초상·음악 교체는 문제가 아니다 — 이 커뮤니티는 원래 계속 새 그림을 만들고 좋아한다.

### 10-2. 저작도구 목표

- **자유도**: RED가 엔진 빈칸에 끼워 넣은 것들(자유모드·회차 특전·숨은 장수·고유 자원·보스 기믹)을 정식 데이터 기능으로.
- **편리함**: "스크린샷 주면 AI가 고친다"는 기대치가 이미 있다 → AI가 다루기 좋은 데이터 + 깨졌는지 자동 검증.
- **배포**: 링크, 모바일, 버전 관리, 세이브 호환.
- **권리와 보상**: 수익 분배, 에셋 사용 범위, 출처 표시, REMIX 허락(카페의 "원작자 허락" 문화와 그대로 맞물림).

### 10-3. SRPG 플랫폼 확장 순서

플랫폼은 **SRPG용**이지 삼국지용이 아니다(트로이가 증명: 데이터팩 교체만으로 다른 게임).
1. 삼국지로 시작 — 가장 큰 코어층, 제작자가 이미 여기 있다.
2. 브랜딩 — 완성작으로 "여기서 만든 SRPG의 퀄리티"를 보여준다.
3. SRPG 콘텐츠 확장 — 트로이·초한·한국사·아이돌·판타지(카페 안에서 이미 수요 확인). 공식과 제작자가 함께.
4. 다른 장르 엔진 — 플랫폼 층(배포·수익 분배·에셋 권리·스토리 에디터·AI 친화 데이터)은 재사용, 엔진만 추가. SRPG 생태계가 도는 걸 확인한 뒤.

**이름**: 플랫폼 이름(장르·소재 중립)과 첫 작품 이름(삼국지 · 유비 편)을 분리한다. 현재 앱 타이틀은 "삼국지 SRPG (가칭)".

### 10-4. 커뮤니티 진입 시

- 첫 문장은 **자체 제작 에셋, 기존 자료 미사용**. "또 하나의 이식판"으로 보이면 안 된다.
- 제작자들에게 먼저 다가간다 — 유저는 제작자를 따라온다(RED 한 작품에 3개월 후기 90개).
- 기본 음악팩을 넉넉히 제공 — AI BGM 파이프라인을 여기에 쓴다.

## 11. 우리 판단의 수정

- **시뮬레이터 해자는 생각보다 얕다.** AI를 쓰는 개조자는 필요할 때 즉석으로 측정 도구를 만든다(복각판 2.0). 차별점은 "측정할 수 있다"가 아니라 **모든 변경에 자동으로 도는 게이트 + 한 플랫폼에서의 관리**다. (시뮬레이션 전략 문서 §12에 반영)
- **"AI로 개조하기 쉬움"도 우리만의 무기가 아니다** — 그쪽도 이미 한다. 차별은 **AI가 만든 결과가 깨졌는지 검증해주는 것**.
