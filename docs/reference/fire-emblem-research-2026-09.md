# 파이어엠블렘 조사 — 트로이를 파이어엠블렘 문법으로 만들기 위한 레퍼런스

**조사일**: 2026-09-19 · **목적**: 영어권 첫 콘텐츠 후보인 **트로이**를 파이어엠블렘(이하 FE) 문법으로 설계하기 위한 세계관·스토리·캐릭터·시스템·시장 분석 · **관련**: [조조전 커뮤니티 조사](jojo-club-community-research-2026-09.md) §10-3·§12, master-plan 미결 ①(2탄 공식 콘텐츠), 트로이 샘플(`apps/web/src/troia/`, `packages/data/json/troia/`, `docs/troia/first-battle/`)

> **선**: 가져오는 건 **규칙·구조·역할 패턴**뿐이다. FE의 이름·캐릭터·세계관·그림체·UI 모양, "FE의 정신적 후속작" 같은 마케팅은 쓰지 않는다(영걸전과 같은 선, game-design §1). 트로이 쪽 인물·이야기는 일리아스·서사시권·아이네이스(퍼블릭 도메인)에서 가져온다. 아래 원형 이름(재건·카인과 아벨 등)은 팬 용어라 **내부 문서에서만** 쓴다.

---

## 0. 결론

1. **트로이는 FE 문법과 궁합이 특히 좋다.** FE는 개성 있는 영웅 개인들의 이야기이고, 일리아스도 그렇다. 영구 사망의 무게(파트로클로스·헥토르·아킬레우스), 지원 대화(아킬레우스–파트로클로스), 대화 영입(글라우코스), 신의 개입(스테이지 기믹), 양쪽 시점(아킬레우스 편 / 헥토르 편)이 원전에 다 있다.
2. **FE 팬이 가장 높이 치는 두 작품의 강점 — 비극(성전의 계보)과 양쪽 모두의 정당성(풍화설월) — 을 일리아스는 원전 자체로 갖고 있다.**
3. **판매를 끈 건 이야기와 관계다.** 전투·맵이 시리즈 최고라던 인게이지(161만)보다 이야기·관계가 강한 풍화설월(412만)이 두 배 이상 팔렸다. 조조전 온라인에서 연의가 가장 사랑받은 것과 같은 패턴.
4. **FE 최대 고질병(무작위 성장 → 세이브·로드)을 우리는 이미 해결했다.** 우리 성장은 병과 등급계수 누적의 결정론이다(`packages/engine/src/growth.ts`, `combat.ts`). FE가 옵션으로 추가한 "고정 성장"이 우리 기본값 — 영어권 FE 팬에게 바로 통하는 장점.
5. **시장: 본편은 서구, 모바일은 일본.** 풍화설월 판매의 절반 이상이 북미. 히어로즈 매출은 일본 54~58%·미국 29~32%. 우리 모델(무료+광고+코스메틱)에선 플레이어 수가 중요 → **트로이는 영어 먼저, 서구 대상.** "소재를 바꿔도 이 플랫폼의 게임이 글로벌에서 통하는가"를 검증하는 실험이 된다.

## 1. 세계관 공식

작품마다 대륙이 다르고 서로 연결되지 않지만(아카네이아·발렌시아·유그드랄·엘리베·마기 바르·테리우스·퍼거스·엘리오스) 뼈대는 같다.

| 공식 | FE | 트로이 |
|---|---|---|
| 여러 왕국의 대륙 전쟁 | 둘 이상의 나라가 한 대륙에서 싸운다 | 에게해 — 그리스 연합군 vs 트로이와 동맹 |
| 주인공은 왕족(로드), 쓰러지면 게임오버 | 왕자·공주 또는 용병 | 아킬레우스(프티아 왕자) / 헥토르(트로이 왕자) |
| 신화적 존재 | 용과 신 | 올림포스 신들 — 전장에 직접 개입 |
| 성스러운 무기 | 제목의 「파이어엠블렘」이 매번 다른 형태(방패·문장·보석) | 헤파이스토스가 만든 아킬레우스의 갑옷, 헤라클레스의 활, 트로이의 신상 팔라디온 |
| 배후 조종자 | 전쟁을 부추기는 흑막 | 에리스와 황금 사과(트로이 샘플 프롤로그에 이미 있음) |
| 세대 서사 | 부모 → 자식 | 아킬레우스 → 네오프톨레모스 |

## 2. 스토리

> 이 절은 조사 중 기억 기반으로 정리한 요약이라 세부 고유명사·순서는 틀릴 수 있다.

**원조 — 아카네이아(마르스)**: 타락해 가는 용족 중 지룡 메디우스가 돌루아를 세워 대륙을 노리고, 영웅 안리가 신룡 나가의 힘이 깃든 신검 팔시온으로 쓰러뜨린다. 백 년 뒤 메디우스가 부활해 알테아가 무너지고, 피신한 왕자 **마르스**가 군을 모아 나라를 되찾고 메디우스를 다시 쓰러뜨린다. 2부에선 옛 동맹 하딘이 황제가 되어 폭군으로 변하는데, 흑마도사가 어둠의 보주로 조종한 것이었다. 마르스는 다섯 보주를 모아 방패 「파이어엠블렘」을 완성한다 — 시리즈 이름의 유래는 **보주를 끼우는 방패**다.

| 대륙(작품) | 한 줄 | 팬들이 꼽는 점 |
|---|---|---|
| 유그드랄(성전의 계보) | 1세대 영웅이 모함당해 불타 죽고, 2세대 아들이 대륙을 해방. 배후에 흑룡 교단 | 시리즈 최고의 비극, 2세대 구조 |
| 엘리베(봉인의 검·열화의 검) | 인간과 용의 대전쟁 이후. 세 로드가 흑막을 쫓는 이야기 → 20년 뒤 그 아들이 용 부활을 막는 이야기 | 같은 세계를 두 세대로 |
| 마기 바르(성마의 광석) | 쌍둥이 왕족, 마왕을 봉인한 성석을 부수는 제국, 흑막에 몸을 빼앗긴 친구 | 친구가 적이 되는 비극 |
| 테리우스(창염의 궤적·여신의 새벽) | 용병 주인공이 침략당한 나라를 되찾는다. 인간과 짐승으로 변하는 종족 사이의 차별이 핵심 | 서민 주인공, 무거운 주제 |
| 이리스(각성) | 아카네이아의 먼 미래, 마르스의 후손, 미래에서 온 딸, 사악한 용. 주인공 군사가 사실 그 용의 그릇 | 시간여행, 결혼·자녀 |
| (if) | 태어난 나라와 키워준 나라 중 선택 → 3갈래 | 선택 분기 |
| 퍼거스(풍화설월) | 사관학교 교사가 한 학급을 맡고, 5년 뒤 세 학급 반장이 서로 전쟁. 교회 수장의 정체가 용 | 어느 편에도 이유가 있다 |
| 엘리오스(인게이지) | 기억 잃은 신룡이 역대 영웅을 소환하는 반지를 모은다 | 전투 호평, 이야기 혹평 |

**반복 패턴**: ① 나라를 잃은 왕족이 군을 모아 되찾는다 ② 동료·친구·가족이 적이 된다(대개 조종당해서) ③ 배후에 신·용·교단 ④ 세대를 건너는 이야기 ⑤ 가장 사랑받는 작품은 비극과 도덕적 회색이 강하다.

**트로이 대입**: 왕들의 연합군(①), 황금 사과로 전쟁을 부추기는 신들(③), 아킬레우스–아가멤논 불화로 최강 전사 이탈(②), 아킬레우스 → 네오프톨레모스(④), 헥토르를 가장 인간적으로 그리는 일리아스·주인공들이 다 죽는 결말(⑤).

## 3. 캐릭터 원형 — 로스터 설계 공식

팬들이 붙인 이름이지만 시리즈 내내 같은 역할이 반복된다.

| 원형 | 역할 | 트로이(일리아스 등) |
|---|---|---|
| 재건(노장) | 처음부터 있는 강한 노기사, 성장 낮음, 주인공의 스승 | 포이닉스 — 아킬레우스를 키운 노스승 |
| 오이페이(젊은 호위) | 초반 강하고 성장도 좋음 | 아우토메돈 — 전차 몰이꾼 |
| 카인과 아벨(붉은·푸른 2인조) | 같은 병종 콤비, 힘/속도 | 두 아이아스 — 원전에서 늘 짝으로 불림 |
| 오그마(용병 대장) | 고르게 강한 전사 | 디오메데스 |
| 줄리안(의적) | 약하지만 특수 능력 | 오디세우스 — 밤에 잠입해 레소스의 말을 훔친다(10권) |
| 레나(힐러) | 초반 회복 담당, 보통 구출해서 합류 | 마카온·포달레이리오스 — 의술의 신의 아들들 |
| 나바르(적 검사, 대화로 영입) | 적으로 나왔다가 말을 걸면 합류 | 글라우코스 — 디오메데스와 싸우지 않고 갑옷 교환(6권) |
| 메릭·린데(마법사) | 첫 마법사 | 예언자 칼카스 / 트로이 쪽 카산드라·헬레노스 |
| 고토(후반 합류 최강자) | 늦게 오지만 능력치가 매우 높음 | 필록테테스 — 헤라클레스의 활을 들고 막바지 합류 |
| 에스트(늦게 오는 잠재력 괴물) | 저레벨 합류, 키우면 최강 | 네오프톨레모스 |
| 백익 삼자매 | 세 자매 기사단 | 아마존 — 펜테실레이아와 전사들 |
| 말레두스(군사) | 전투에 안 나오는 참모 | 네스토르 |
| 가작(첫 보스) | 도적 두목, 상성상 주인공 유리 | 키크노스 — 상륙 첫 전투(트로이 샘플 「낯선 해안」) |
| **카뮈(명예로운 적장)** | 자기 편이 틀린 걸 알면서 충성 때문에 싸우고 죽는다 | **헥토르 — 이 원형의 완벽한 예.** 아킬레우스 편에선 최종 보스, 헥토르 편에선 주인공 |

## 4. 시스템

| 시스템 | FE | 우리 현황 → 트로이 적용 |
|---|---|---|
| **무기 상성** | 검 > 도끼 > 창 > 검, 마법도 3각. 효과는 명중 ±15%·위력 ±1 정도로 작음. 상성을 뒤집는 무기. 풍화설월은 폐지, **인게이지는 이기면 상대가 반격 불가("브레이크")** | 병종 상성(방어 보정 0.75/1.25) 있음. "이기면 반격 봉쇄"는 숫자보다 눈에 띄는 결과라 참고 |
| **영구 사망과 모드** | 클래식(영구 사망) / 캐주얼(퇴각 후 복귀) / 피닉스(다음 턴 부활, if). **모드와 난이도는 별개로 선택** | 퇴각만 있음(game-design §10). **클래식을 데이터 플래그로 추가** — 트로이 서사의 핵심이자 플랫폼 기능 |
| **되감기** | 풍화설월 「천각의 박동」 — 처음 3회, 최대 13회(최고 난이도 10회), **게임오버 직전 자동 발동**. 에코즈·인게이지에도 있음 | P2 턴 되돌리기 계획. **횟수 제한 자원** + 게임오버 직전 자동 발동이 좋은 선례 |
| **진짜 명중률** | GBA판부터 난수 2개 평균 → 화면 80%가 실제 92%, 20%가 실제 8%. 체감 확률에 맞춘 조작. 최신작은 50% 이상에만 보정 공식 | 시드 명중(Phase B) 있음. **곡선 결정만 남음**(정직 표시 / 체감 곡선 / 히어로즈식 확률 없음). 어느 쪽이든 시드·시뮬과 충돌 없음 |
| **성장률** | 능력치별 확률로 상승 → **세이브·로드와 "운 나쁜 유닛"이 고질병**. 해법: 빈 레벨업 재굴림(GBA), 동적 성장(신 암흑룡), 고정 모드(창염의 궤적·인게이지), 기댓값(히어로즈) | **이미 결정론**(병과 등급계수 누적). 새로 만들 게 아니라 **알릴 장점** |
| **지원(인연)** | 함께 싸우면 포인트 → C/B/A(/S) 대화 해금, 인접 시 명중·회피·회심·회심 회피 보너스, 인연 수 제한(창염의 궤적: 1명), S 결혼·자녀(각성·if), 짝 엔딩 | 없음 → 조사 문서 §9에 추가됨. 보너스는 확정 수치, 대화는 스토리 에디터 데이터 |
| **대화 영입** | 특정 아군이 적 옆에서 말을 걸면 합류, 적 대사로 힌트. 최신작은 노란 칸·"Talk!" 말풍선 | 없음 → 글라우코스 장면 |
| **외전(숨은 장)** | 조건(턴 제한 내 클리어·특정 인물 생존·마을 보호 등)을 채우면 열리는 선택 스테이지. 전용 동료·전설 무기 | 보물 조건 시스템을 "숨은 스테이지 해금"으로 확장. RED 숨은 장수 해금과 합치면 회차 구조 |
| **무기 내구도** | 풍화설월 유지(귀찮다는 불만) → 인게이지 폐지 | 원래 없음 — 유지 |
| **전투 사이 거점** | 풍화설월 수도원(달력·수업·활동), 인게이지 비행섬(미니게임·식사) | 우리 원칙(막간 = 이야기 + 출진 준비, 내정 금지)과 달라 따라가지 않는다. 지원 대화를 막간 이야기 안에서 |

## 5. 맵·목표·난이도

**목표 6종**: 제압(가장 흔함 — 주인공이 옥좌·성문에서 명령) / 섬멸 / 보스 격파 / 방어·생존(보통 7~15턴, 방어는 지킬 대상 있음) / **탈출(적이 훨씬 강하거나 많을 때)** / 도착(누구든 도달). 우리 목표 데이터(섬멸·도달·생존·호위)와 거의 대응.

**난이도가 바꾸는 것**: 적 실질 레벨↑, 적 수·배치, **증원이 나타난 턴에 바로 행동**, **AI가 약한 유닛을 더 노림**, 적 장비, 플레이어 자원 축소(경험치↓·상점 가격↑). → **우리 시뮬레이터 봇 실력 티어를 적 AI 난이도로 재사용**할 수 있다.

**매복 증원**: 나타나자마자 행동하는 증원은 FE 커뮤니티에서 가장 미움받는 설계. 원칙은 **"증원은 예고한다"**(보스 대사 등). → 에디터 검증에 **예고 없는 즉시 행동 증원 경고**. 복각판 2.0 「적장 출진」도 같은 불만에서 나옴.

**전장의 안개**: 시야 밖 적은 안 보이고 공격 불가. 도적 계열 시야가 넓고 횃불로 확장. 정찰의 가치를 만든다. 우리에겐 없음 → 트로이 밤의 정찰 스테이지.

**좋은 맵 원칙**(분석 글): 목표 유형 섞기 / 빈 공간 없애기(맵 축소, 모든 구역에 뭔가) / 버티기만 하는 플레이 막기(시간 압박) / 길목 + 여러 경로 / 적 배치로 꼼수 봉쇄(비행 우회 → 궁수). → **시뮬레이터·에디터 지표로 옮길 수 있다**(빈 공간 비율·경로 수·길목 빈도 — 시뮬레이션 전략 문서의 "천장 지표"와 겹침).

## 6. 두 개의 철학 — 이야기가 팔린다

| | 풍화설월 (2019) | 인게이지 (2023) |
|---|---|---|
| 강점 | 이야기·캐릭터·관계, 4갈래 분기 | 전투·맵 디자인 — "시리즈 최고, 전술 RPG 전체에서도 최상급" |
| 약점 | 쉬운 난이도 | 이야기 "형편없다", 지원 대화 "지루하다" |
| 판매 | **412만** | 161만 |

그 외 판매: if 309만, 각성 237만. 각성 직전 닌텐도가 "25만 장 못 넘기면 시리즈 종료" 조건을 걸었고, 각성은 캐주얼 모드 등 새 요소로 이를 넘겨 시리즈를 살렸다.

## 7. 파이어엠블렘 히어로즈(모바일)

- 2017-02 출시. 첫날 290만 달러, 첫해 약 3억 달러, 2022년 **10억 달러**(닌텐도 모바일 최초), 2025-02 누적 **약 13억 달러** — 시리즈 최고 수익. 평론 72점(전략성·입문 친화 호평, 이야기 약함·스태미나 비판).
- 모바일용 설계: **8×6 맵·4명**, **전투 결과 확정(명중 확률 없음)**, 내구도 없음, 성장 기댓값, 스킬 계승.
- 수익원: 가챠·스태미나·월정액(Feh Pass). 벨기에는 도박 규제로 2019년 서비스 중단.
- 의미: ① **짧게 자른 SRPG는 모바일 대중 시장에서 크게 통한다** ② 확정 전투가 모바일에서 먹혔다 — 우리 방향과 맞고, "확률 없는 모드"도 선택지 ③ 우리 유비 편은 원작 맵 그대로 평균 57×39 — 전체 축소보다 **짧은 모드(도전·로그라이크 탑)를 작은 맵으로** 따로 두는 게 현실적 ④ 수익 엔진(가챠·스태미나)은 우리 불가침선이라 따라가지 않는다 ⑤ 여기서도 약점은 이야기.

## 8. 지역별 시장

| | 가장 큰 시장 | 근거 |
|---|---|---|
| 본편(한 번 사는 게임) | **북미** | 풍화설월 판매 절반 이상이 북미 |
| 히어로즈(모바일 가챠) | **일본** | 매출 54~58% 일본, 미국 29~32%, 캐나다 3% |

원래 일본 내수용이던 시리즈가 대난투로 서구에 알려진 뒤 서구 중심으로 컸다. 일본 비중은 FE 인기보다 일본 모바일 과금 문화를 반영. 한국·중국은 닌텐도 존재감이 상대적으로 약하다. 영어권 FE 팬게임 커뮤니티(FEU, 주간 활동 약 1,100명)는 닌텐도 IP라 수익을 못 낸다 — 조클 제작자와 같은 처지(조사 문서 §12).

## 9. 트로이 적용

**스테이지 후보 — 원전에 이미 있다**

| 스테이지 | 원전 | 목표·기믹 |
|---|---|---|
| 상륙전 | 서사시권 「키프리아」 | 첫 보스 키크노스(현 샘플 「낯선 해안」) |
| 밤의 정찰 | 일리아스 10권 | 안개 맵 + 잠입, 레소스의 말 탈취 |
| 함선 방어 | 15권 — 헥토르가 함선에 불을 지르려 함 | 방어 7~15턴 |
| 파트로클로스 출전 | 16권 | 보스(사르페돈) 격파 → 파트로클로스 전사(스크립트) |
| 강의 분노 | 21권 — 강의 신이 아킬레우스를 덮침 | 신이 일으키는 지형 재해 |
| 헥토르와의 결투 | 22권 | 결투 스테이지 |
| 불타는 트로이 | 아이네이스 2권 | **탈출** — 헥토르(트로이) 편의 마지막, 아이네이아스가 가족을 데리고 탈출 |

**모드**: 아킬레우스 편 / 헥토르 편(「인물명 편」 규칙, scenario.md §5). 같은 전투를 양쪽에서.

**우선순위**: ① 클래식/캐주얼 선택 ② 지원 대화 ③ 대화 영입 + 외전 ④ 횟수 제한 되감기(P2) ⑤ 명중률 곡선 결정. 결정론 성장은 새로 만들 것 없이 알리면 되는 장점.

**콘텐츠 전략 초안**: 한국·중국어권 = 삼국지 유비 편 → 초한 / 영어권 = 트로이(FE 문법). master-plan 미결 ①(2탄 공식 콘텐츠)의 답이 "언어권마다 다르다"일 수 있다 — 결정은 길중.
