# 1–5장 난이도 조정 결과 — 2026-09-15

편집 프로젝트 791e33c0-eb83-4b40-8b91-f58843ad3a64 및 실제 게임 revision 10에 반영했다. 기존 이야기·맵·카탈로그·사용자가 추가한 동탁과 사건은 보존했다. 적벽의 별도 시연용 화공만 제거하고 정식 화공으로 통합했다.

## 변경

- 전투 순서에 맞춰 기본 출전 레벨을 1–27로 정리하고 적·증원 레벨도 함께 조정했다.
- 부대 훈련: 처음 클리어한 서로 다른 전투 수 + 1을 최소 출전 레벨로 적용한다(최대 30). 미출전 지원 장수와 새 영입 장수도 따라오며, 높은 기존 레벨과 장비는 유지된다. 반복 클리어로 훈련 레벨이 오르지 않는다.
- 적이 강 앞에서 멈추던 이동 정책을 지형 경로 비용 기반으로 수정했다. 소패에서도 실제 교전이 발생한다.
- 장각을 후방으로 이동하고 병력을 30% 늘려 즉시 보스만 잡고 끝나는 구간을 완화했다.
- 호로관 적 병력 15% 감소, 소패 20% 감소·9턴 방어, 관도 탈출 적과 증원 병력 45% 감소, 여남 20% 감소. 새 경로 탐색과 실제 출전 장비를 기준으로 과도한 추격 압박을 조정했다.
- 장판파 탈출 지점을 (34,18)에서 (33,18)로 변경했다. 기본 장비로 마지막 한 칸 앞에서 반복 패배하던 문제를 완화했다.
- 강하 방어 시간을 35→18턴으로 단축했다.
- 삼강구 적 병력 20%, 적벽·화용도 60% 증가. 적벽 정식 화공은 8→4턴으로 앞당겼다.
- UI를 통한 전투 테스트 드라이버가 이동 후 일반 공격만 고르던 오류도 수정했다. 실제 정책과 동일하게 표적·필살·회복을 선택하며 순수 엔진과 결과가 일치한다.

- pnpm test: 1,330개 통과, 기존 원본 바이너리 의존 검사 9개 건너뜀.
- pnpm typecheck: 통과.

- 실제 게임 API: revision 10, 27개 전투, 동기화 경고 없음. 편성 페이지 HTTP 200.
- 초반에는 높은 자동 승률을 유지하고, 중반에는 퇴각 부담과 다양한 목표, 후반에는 자동 전투 실패 가능성을 두었다. 모든 전투를 이전 전투보다 어렵게 만들지는 않았다.

- 열어 둔 게임은 새로고침 후 새 전투부터 적용된다. 중단한 전투 이어하기는 저장된 이전 게임 버전을 보존한다.
